# IoT Data Analytics (MDS462)
**Course Overview:**
A Trimester 4 Elective exploring the massive, continuous streams of data generated by the Internet of Things (smart sensors, wearables, embedded devices).

**Key Topics Covered:**
* IoT Architecture and edge computing limitations.
* Streaming Data Processing (Apache Kafka, Flink).
* Time-series sensor fusion and signal processing.
* Predictive Maintenance algorithms for industrial hardware.
* MQTT, CoAP, and Low-Power Wide-Area Network (LPWAN) protocols.
* Security vulnerabilities in IoT hardware.

**Learning Outcomes:**
Students will be prepared to ingest, process, and deploy machine learning models directly onto low-power edge devices and microcontrollers (TinyML) to predict hardware failures before they occur.
